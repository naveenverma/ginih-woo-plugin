# Ginih — WooCommerce Payment Gateway

WooCommerce payment gateway for [Ginih](https://ginih.com/) — businesses receive payments funded by debit/credit card into a Ginih account, with programmatic settlement from any web service.

## What it does

- Registers a WooCommerce payment method for Ginih
- Talks to Ginih’s REST payment API (card-funded account flows)
- Surfaces gateway settings (API keys, mode, icons) in Woo admin

## Stack

PHP · WordPress · WooCommerce `WC_Payment_Gateway` · Ginih REST API
